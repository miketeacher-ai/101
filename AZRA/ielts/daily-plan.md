## How to Use This Plan

- **AM (70 min):** Primary skill — deep technique work, no timer first 40 min, then timed
- **PM (50 min):** Secondary skill — apply morning technique to new set
- **Micro (15 min):** Error log — classify every miss as timing / knowledge / careless, write ONE fix, schedule revisit in 3 days
- Suggestion column = what to do when stuck, or how to optimize that day

## Daily Optimization Rules

1. **15-min error log is non-negotiable** — one classified error > one hour blind practice.
2. **Mocks always morning** — afternoon review same day while memory fresh.
3. **One human feedback/week** for Writing/Speaking beats daily self-score.
4. If trajectory stalls 3 days, cut strongest skill 20 min and give to weakest — don't add hours.

## Suggestion Engine (when stuck)

- **Listening stuck at 5.5:** slow audio to 0.8x for 2 days to catch linking, then return to 1.0x — accuracy first, speed second.
- **Reading time fail:** do one untimed accuracy week (no clock) then rebuild 20/20/20 timing.
- **Writing Task 2 stuck:** write only body paragraphs for 3 days (no intro/conclusion) — master one idea.
- **Speaking hesitation:** 10 sec prep → 60 sec talk daily for 5 days, no stopping rule.
