## Day-by-Day: How to Build + Suggestion

### Days 1-5: Project A — Balat Micro-Apartment

| Day | Task | How to Build | Suggestion / Optimization |
|-----|------|--------------|---------------------------|
| 1 | Measure + photograph Balat site; site analysis sheet | How: Borrow tape, measure 3 key dimensions (length, width, height) + window positions. Photo with phone + include person for scale. Draw analysis sheet: sun path, noise, access, structure. | Suggestion: Use your grandmother's apartment if Balat access limited — authenticity > site prestige. Draw analysis by hand, not digital — faster, more personal |
| 2 | Concept sketches (3 options), choose one | How: 30 min per option, trace paper or any paper, no erasing. Option 1: maximize light, Option 2: maximize storage, Option 3: maximize flexibility. Pin up, choose with gut + 2 criteria (light, privacy). | Suggestion: Time-box to 30 min each — prevents perfectionism. Ask one peer/family member to pick favorite (external eye) |
| 3 | Plan + section at 1:50, hand-drawn + dimensioned | How: Use graph paper, 1 unit = 1 cm = 0.5m. Draw plan (top view) and one section (cut through). Add dimensions, north arrow, scale bar, furniture. | Suggestion: Hand-drawn is expected for high-school — don't chase CAD perfection. One accurate plan > three sloppy renders |
| 4 | SketchUp Free model, basic massing + openings | How: School computers after hours, SketchUp Free web. Model only walls, openings, major furniture — no materials yet. Use components for windows. | Suggestion: Watch one 20-min SketchUp tutorial, then model — don't binge tutorials. Model at real dimensions, not approximate |
| 5 | 2 renders + layout pages 1-3 of PDF | How: SketchUp Styles → export 2 views (plan + perspective). Place in Canva (free) with title, concept sentence, plan, section, render. Check print resolution (export 300dpi). | Suggestion: Keep Canva layout minimal: white background, one font, 2 images per page max. Portfolio reviewers spend 30 sec per page — clarity wins |

### Days 6-10: Project B — Kadıköy Bus Stop

| Day | Task | How to Build | Suggestion |
|-----|------|--------------|------------|
| 6 | Observation at bus stop (peak 7:30-8:30 + off-peak 14:00), photo set + notes | How: Silent observation, no interviews yet. Note: where people stand, shelter use, seating, information clarity, women's safety after dark, rain behavior. Sketch quick plan of existing stop. | Suggestion: Go with friend for safety + second observer. Take photos with people blurred for privacy. Count users (e.g., 32 in peak hour) — numbers make portfolio credible |
| 7 | 5 user interviews, synthesis into needs | How: 5 questions: Where do you wait? What bothers you? What would help? Interview 2 women, 1 elder, 1 student, 1 worker. Note exact quotes. Group into 3-4 need clusters (shade, seating, info, safety). | Suggestion: Interviews 3 min each, not 10 — respect time. One surprising insight (e.g., "timetable faded") is worth more than 5 generic answers |
| 8 | Concept boards (circulation, shelter, seating, information) | How: 4 boards, each with quick sketch + 2-sentence explanation. Circulation = how people move/wait. Shelter = roof/wind. Seating = perching vs sitting. Information = legible timetable. | Suggestion: Use tracing paper over photo of existing stop to show "before → after" — instant clarity for reviewer |
| 9 | Model or render set | How: Choose one: quick cardboard model (1:20, reclaimed) OR SketchUp render (if model would take >4h, choose render). Show at least 2 views. | Suggestion: Cardboard model photographs better than mediocre render — if rendering skills weak, build physical |
| 10 | PDF pages 4-6 | How: Place observation photo + need clusters + concept boards + model/render in Canva. Add user quotes as callouts. | Suggestion: One page = one idea. Pages 4: observation, 5: needs + concepts, 6: final design. Don't cram |

### Days 11-15: Project C + Assembly — Seismic Pavilion

| Day | Task | How to Build | Suggestion |
|-----|------|--------------|------------|
| 11 | Seismic precedent research (Japan, Chile, Turkey codes) | How: 3 precedents, one per country. For each: 1 image + 2 sentences (structural system + why it survived). Focus on community pavilions/shelters, not towers. Source: ArchDaily, Turkey's TBDY code summary. | Suggestion: Choose precedents that are pavilion-scale — reviewers see through tower research for pavilion project. Cite with links, not formal bibliography |
| 12 | Massing sketches, structural diagram | How: 4 massing options, focus on base isolation or braced frame idea. Draw structural diagram (arrows showing load path, bracing). Keep pavilion <50 m², single story. | Suggestion: Structural diagram is star of this project — make it large, clear, with 2 colors (structure vs enclosure). Don't over-detail joints |
| 13 | Pavilion render + narrative board | How: One hero render (perspective with people) + one plan/section. Narrative board: 150 words linking Balat crack + 1999 story to design intent (safety + beauty, not just safety). | Suggestion: Narrative board is where personal story meets technical — this is what US architecture reviewers remember. Write it, then read aloud to check flow |
| 14 | Assemble full PDF 8-12 pages, check print resolution | How: Canva: cover (title + name), pages 1-3 (Project A), 4-6 (B), 7-9 (C), 10 (reflection). Export PDF Print, check each image 300dpi (zoom 100% — if pixelated, re-export). Keep <15 MB. | Suggestion: Cover = one strong render + name + "Selected Works 2026" — no busy graphics. Check PDF on phone — if readable on phone, reviewer will see it |
| 15 | Peer/mentor review, export final PDF | How: Send PDF to art teacher + one peer + one family member. Ask: which page is weakest? Fix only that page. Export final PDF, save in 3 places (drive, phone, email to yourself). | Suggestion: Fix only weakest page — resist redesigning all. "Done" is better than "perfect". Definition of Done: 3 projects × plan/section/render/narrative, PDF 8-12 pages, <15 MB, saved ×3 |

## Quality Gates (check before Day 15)

- [ ] Every drawing has scale and north arrow
- [ ] Every render has dimensions noted
- [ ] Every project has one-sentence narrative linking site → concept → design
- [ ] PDF exports at print resolution, <15 MB, readable on phone

## Tool Optimization

- Hand sketching > CAD for speed in Days 1-3
- SketchUp Free web (not desktop) — no install, works on school computers
- Canva free templates — don't design layout from scratch; use grid
- Phone photos need person for scale — reviewer needs human reference
