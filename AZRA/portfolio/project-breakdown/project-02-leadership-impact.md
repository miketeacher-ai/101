# Project 02: Community Build & Workshop (Days 16-30) — How to Build Each Day

**Student:** Azra | **Major:** Architecture | **Sprint:** Day 1 Mon Aug 24 - Day 45 Wed Oct 7, 2026

Deliverable: "Tasarım ve Paylaş / Design for Community" — 5-session workshop for 20+ peers + built courtyard library nook, documented with metrics and supervisor letter. 4-5 hrs/day. Optimized: zero budget, reclaimed materials, one built thing > ten proposals.

## Workshop Curriculum: 5 Sessions (optimized)

| # | Session | Content | Activity | How to Teach | Suggestion |
|---|---------|---------|----------|--------------|------------|
| 1 | Seeing Balat | Facade analysis, measuring | Measuring tape exercise | Bring tape, measure one facade together, then pairs measure one block | Start with doing, not talking — tape in hands in first 5 min |
| 2 | Human Scale | Ergonomics, seating heights | 1:1 tape mock-up on floor | Tape human scale on floor (chair, table, nook footprint) | Full-scale tape mock-up is magic — people understand scale instantly |
| 3 | Community Needs | Interview synthesis | Needs mapping | Group 5 interviews into 3 clusters on sticky notes | Sticky notes > slides — visible, movable, collaborative |
| 4 | Build Prep | Materials, safety, joinery | Tool demo | Show 3 joints (butt, lap, screw) on scrap wood | Demo one joint, let each pair try one — hands-on memory |
| 5 | Design Review | Final proposal critique | Peer feedback boards | Pin-up nook proposals, each group presents 2 min, peers give one "I like" + one "what if" | "Like / what if" is kinder and more useful than "good/bad" |

## Day-by-Day: How to Build + Suggestion

| Day | Task | How to Build | Suggestion / Optimization |
|-----|------|--------------|---------------------------|
| 16 | Venue permission (school hall or community center) + dates fixed | How: Write 1-page permission letter (what, why, when, supervision, safety). Deliver in person with sketch. Offer to share documentation with school. | Suggestion: Ask vice principal + janitor + one teacher — janitor knows where sun actually falls at 2pm and where power outlets are. Permission is logistics, not just signature |
| 17 | Recruit 20+ peers via poster + class announcements | How: One poster (A3, hand-drawn, not printed) with date + 3 benefits (draw, build, certificate). Announce in 3 classes, 60 sec each. Sign-up sheet with name + availability. | Suggestion: Poster hand-drawn signals "we make things" better than Canva. Personal 60-sec pitch beats Instagram post for 20 sign-ups |
| 18 | Session 1 (Seeing Balat) + attendance + feedback form | How: 60 min: 10 min intro, 25 min measuring, 15 min sharing, 10 min feedback form (3 questions: what learned, what confused, what to change). Take attendance photo. | Suggestion: Feedback form is gold — read it that evening and change Session 2 based on it. One concrete change > five planned improvements |
| 19 | Revise from feedback; Session 2 (Human Scale) | How: Morning: read feedback, adjust session plan (e.g., if "too much talking," cut 5 min lecture, add 5 min doing). Afternoon: run Session 2. | Suggestion: Show you listened: start Session 2 with "Yesterday you said __, so today we will __" — builds trust fast |
| 20 | Nook proposal to administration (site, dimensions, materials, safety note) | How: One-page proposal: site photo + dimensioned sketch (plan + section) + materials list (reclaimed pallets, screws, sandpaper, paint) + safety note (adult supervision, sanded wood, no power tools without adult). Include maintenance plan. | Suggestion: Proposal with dimensions and safety note gets "yes" faster than essay. Show you thought about who cleans/maintains — administration's real worry |
| 21 | Session 3 (Community Needs); source reclaimed pallets/materials list | How: Session 3 as per curriculum. After session: list materials needed vs available. Source pallets: ask local shops, school storage, municipality. Count screws needed. | Suggestion: Source materials before Session 4 — nothing kills workshop momentum like "we don't have wood." Have backup site (second courtyard corner) if first denied |
| 22 | Weekly review: attendance tracker live; confirm build schedule | How: Count unique attendees so far (target 12 by now, 20+ by end). Check build schedule: 3 build days (Days 24,26,27) + install Day 28. Confirm adult supervisor availability for each. | Suggestion: Weekly review is where 50 points come from — not from building, but from noticing attendance is 14 not 20 and adding personal invites for Session 4 |
| 23 | Session 4 (Build Prep) with tool safety | How: Tool safety demo + practice on scrap. Each pair makes one joint. End with nook assignment: who builds which part. | Suggestion: Safety demo is where you earn adult trust — do it seriously, with goggles, even if it feels slow. Adults remember safety, not speed |
| 24 | Build Day 1: frame | How: Morning: build frame on ground, check wobble (diagonal brace if wobbles). Sand all surfaces. Photo every step. | Suggestion: Frame wobble test: push from side — if it moves, add diagonal. Don't ignore wobble and hope. Reclaimed pallets hide nails — scan with magnet, pull all nails first |
| 25 | Session 5 (Design Review) | How: Final session: pin-up nook proposals, present to group, vote on finish details (color, shelf height). Celebrate with tea + photos. Collect final feedback. | Suggestion: Session 5 is celebration + documentation — take group photo with nook frame behind. This photo will be portfolio gold |
| 26 | Build Day 2: shelving/seating | How: Add shelves/seating to frame. Test weight (sit, stack books). Sand again. | Suggestion: Shelves must hold 20 books without sag — test with actual books. Seating must hold 80 kg — sit on it yourself first |
| 27 | Build Day 3: finish + install in courtyard | How: Paint (one color, not three — time). Install in courtyard, level with shims if ground uneven. Clean area. | Suggestion: One color + one accent is faster and looks better than three colors badly painted. Install level — wobbly nook looks unfinished even if build is good |
| 28 | Photo/video documentation (before/after, process, testimonial quotes) | How: Before/after from same angle. Process: 5 best photos (measuring, workshop, building, installing, using). 2 quotes from participants (ask: "what did you learn?"). One 30-sec video with phone, horizontal. | Suggestion: Quotes: ask before they leave, not later. "What will you tell family about today?" gets better answers than "Did you like it?" |
| 29 | Impact metrics: participants (20+), hours, before/after photos | How: Count unique attendees (not total visits). Count hours (workshop + build). Assemble metrics page for portfolio: numbers + quotes + photos. | Suggestion: Metrics page for portfolio: 3 numbers (20+ peers, 5 sessions, 1 built nook) + 2 quotes + 3 photos = one page that proves leadership without essay |
| 30 | Supervisor letter requested; checkpoint done | How: Ask supervising teacher for 1-paragraph letter: what, when, how many, your role. Provide bullet list to make it easy. Thank everyone personally. | Suggestion: Provide bullet list to teacher — makes letter specific and fast. Handwritten thank-you to teacher + janitor + participants — remembered longer than certificate |

## Metrics to Capture (for portfolio)

- Unique attendees (target 20+, not total visits)
- Hours (workshop 5×60 min + build 3×4h = ~17h)
- Before/after photo pair from same angle
- Two participant quotes

## Safety Notes (non-negotiable)

- No power tools without adult present
- Sand all reclaimed wood — splinters are preventable failure
- Goggles for sawing/sanding, even if peers laugh
