# 45-Day Intensive SAT Daily Plan — How to Study Each Day

**Student:** Azra | **Major:** Architecture | **Sprint:** Day 1 Mon Aug 24 - Day 45 Wed Oct 7, 2026

3-4 hrs/day. Architecture: portfolio > SAT at most schools, but 1150 realistic / 1300 stretch keeps merit options open. Real SAT Sat Oct 3 (Day 41) paper+Desmos. Backup Nov 7. Daily structure optimized for retention, not just coverage.

## How to Study Each Day

- **Warm-up (20m):** 5 RED items from weak-area-tracker — spaced repetition, not new material
- **Topic Block (75m):** One focus from math-topics.md / reading-strategies / writing-grammar → read concept → copy worked example by hand → drill 10 Q untimed → redo misses
- **Timed Set (45m):** 10-15 Q under clock from same topic + mixed review — simulates module pressure
- **Error Loop (30m):** Classify every miss as concept / execution / timing / misread → update tracker cell RED/YELLOW/GREEN → write ONE fix sentence for tomorrow's warm-up
- Suggestion = what to do if topic clicks quickly, or how to salvage if it doesn't

## Optimization Rules

1. **Warm-up is sacred:** 5 RED items every day > 20 new Q. Spaced repetition beats coverage.
2. **Cause labels drive next day:** concept miss → reread topic same evening; timing miss → flag-and-move drill next warm-up.
3. **Days 36-41: nothing new.** Only formula-sheet + RED redos + PT4. Adding new material now lowers score.
4. **Desmos from Week 2:** use for graphing checks, not trivial arithmetic — build fluency, not dependency.
