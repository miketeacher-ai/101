## How to Use This Plan

- **AM (70 min):** Primary skill — technique first 40 min (untimed), then timed 30 min
- **PM (50 min):** Secondary skill — apply technique to new set, focus on transfer
- **Micro (15 min):** Error log — classify every miss as timing / knowledge / careless, write ONE fix
- Suggestion = what to do when stuck or how to optimize that day's economics connection

## Suggestion Engine (when stuck — optimized)

- **Listening stuck at 5.5:** slow audio to 0.8x for 2 days to catch linking, then return to 1.0x.
- **Reading time fail:** do untimed accuracy week, then rebuild 20/20/20 timing.
- **Writing Task 2 stuck:** write only body paragraphs for 3 days (no intro/conclusion) — master one idea.
- **Speaking hesitation:** 10 sec prep → 60 sec talk daily for 5 days, no stopping rule.
