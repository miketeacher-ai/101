## How to Study Each Day

- **Warm-up (20m):** 5 RED items from weak-area-tracker — spaced repetition
- **Topic Block (75m):** One focus from math-topics.md / reading-strategies / writing-grammar → read concept → copy worked example by hand → drill 10 Q untimed → redo misses
- **Timed Set (45m):** 10-15 Q under clock from same topic + mixed review
- **Error Loop (30m):** Classify every miss as concept / execution / timing / misread → update tracker RED/YELLOW/GREEN → write ONE fix sentence for tomorrow's warm-up
- Suggestion = what to do if topic clicks quickly, or how to salvage if it doesn't; economics tie-ins where helpful

3. **Days 36-41: nothing new.** Only formula-sheet + RED redos + PT4. Adding new material now lowers score.
4. **Desmos from Week 2:** use for graphing checks, not trivial arithmetic.
