## Optimization Rules

1. **Two feedback rounds max** — protect voice. Contradiction? Counselor decides.
2. **Batch by type** — why-research together, community together — shared research.
3. **Never add hours** — if behind, cut polish pass, not sleep. Voice check matters more than fourth revision.
4. **Abstract reused** — same abstract for TUBITAK, ISEF, and Common App upload. One effort, three uses.
