# Reading & Writing Strategies (Digital SAT)

**Student:** Elfin | **Major:** Molecular Biology & Medicine | **Sprint:** Day 1 Mon Aug 24 - Day 45 Wed Oct 7, 2026

Digital SAT RW: two adaptive modules, short passages 25-150 words, one Q each, ~75 sec/Q.

## Passage Types

| Type | Expect |
|------|--------|
| Literature | Voice, character attitude, figurative language |
| History/social | Arguments, perspectives, paired texts |
| Science | Hypotheses, findings, study design |
| Poetry | Paraphrase line by line first |

## Question Categories

1. Command of evidence — which quote best supports claim; test each quote.
2. Central idea / purpose — one-sentence paraphrase first.
3. Text structure & purpose — why include this sentence?
4. Cross-text connections — agree/disagree/extend; map each text separately.
5. Words in context — predict your own word BEFORE choices.
6. Transitions — identify logic (contrast, cause, addition).
7. Rhetorical synthesis — work from bullet notes only; match every requirement; eliminate any choice adding/dropping a note.
8. Information & ideas — literal comprehension; must be provable from text.

## Elimination Framework

1. Read question stem first.
2. Read passage once; paraphrase key sentence.
3. Predict answer in own words.
4. Eliminate: extreme language (always/never), half-right, out-of-scope, reversed logic.
5. Between two survivors, pick fully supported by evidence.

## Timing

- ~75 sec/Q; flag >90 sec and move.
- Module 1 accuracy sets Module 2 difficulty — early precision pays twice.
- No penalty for guessing.

## Vocab-in-Context Method

Replace with "blank", reread for tone/logic, pick synonym fitting direction. Build deck from misses, not giant lists.

## Traps

- True about passage but not answering question.
- Extreme moralizing of neutral science passages.
- Evidence from wrong paragraph.
- Transition where both contrast words fit grammar — logic decides.
