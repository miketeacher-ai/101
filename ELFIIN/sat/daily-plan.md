## How to Study Each Day

- **Warm-up (20m):** 5 RED items from weak-area-tracker — spaced repetition
- **Topic Block (75m):** One focus from math-topics.md → read concept → copy worked example by hand → drill 10 Q untimed → redo misses
- **Timed Set (45m):** 10-15 Q under clock from same topic + mixed review
- **Error Loop (30m):** Classify every miss as concept / execution / timing / misread → update tracker RED/YELLOW/GREEN → write ONE fix sentence
- Suggestion = what to do if topic clicks quickly, or how to salvage if it doesn't; med/bio tie-ins where helpful
