# Project 02: Community Build & Workshop (Days 16-30)

**Student:** Azra | **Major:** Architecture | **Sprint:** Day 1 Mon Aug 24 - Day 45 Wed Oct 7, 2026

Deliverable: "Tasarım ve Paylaş / Design for Community" — 5-session workshop for 20+ peers + a built courtyard library nook, fully documented with metrics and supervisor letter.

> **Reality Check:** One built thing with 20 witnesses beats ten hypothetical proposals. Scope to a single nook/bench that can be permitted and built in 8 days with reclaimed materials.

## Workshop: 5 Sessions

| # | Session | Content | Activity |
|---|---------|---------|----------|
| 1 | Seeing Balat | Facade analysis, measuring | Measuring tape exercise |
| 2 | Human Scale | Ergonomics, seating heights | 1:1 tape mock-up |
| 3 | Community Needs | Interview synthesis | Needs mapping |
| 4 | Build Prep | Materials, safety, joinery basics | Tool demo |
| 5 | Design Review | Final proposal critique | Peer feedback boards |
