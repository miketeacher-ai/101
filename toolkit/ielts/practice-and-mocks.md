# IELTS Practice Materials & Mock Exam Protocol

## Escalation Rules (difficulty must rise with the sprint)
- **L1 (W1):** baseline sets, S1/S2 focus, no hard time caps — target 60–70%.
- **L2 (W2–3):** full question mix, S3/S4 included, exam caps enforced — target 75–80%. Same drill +5 points vs your L1 score or it repeats at higher difficulty.
- **L3 (W4–5):** hardest Academic passages only, trap-dense sets, audio at 1.1×, Task 2 capped at 35 min — target 80–85%.
- **L4 (W6):** exam-strict + over-speed rehearsal — target 85–90% under pressure. No new material, execution only.
- A drill passed at its level is retried **one notch harder** (harder source, tighter cap, or faster audio) — never the same difficulty twice in a row.

## Drill Bank (timed, always logged — level-tag every entry)

### Listening drills (20–30 min each)
| Drill | Setup | Pass standard (rises by level) |
|---|---|---|
| Prediction sprint | Any section: write answer-shape for all questions before audio | L1: 100% predicted · L2+: 100% + answer class (name/number/noun) for each |
| Distractor hunt | Replay a missed section; mark every correction/negation in transcript | Find all traps; note phrasing in error log |
| Spelling gauntlet | 20 hardest words from your error log, dictated at speed | 20/20 twice in a row |
| 1.1× overload *(L3+ only)* | Full test at 1.1× speed | ≥ exam-day accuracy at normal speed |
| Map trace | Any map/plan section, finger on the plan | L1: 8/10 · L2+: 9/10 |
| S4 lecture *(L2+ only)* | Full Section 4, notes with symbols | L2: 5/10 · L3: 7/10 · L4: 8/10 |

### Reading drills (30–60 min)
| Drill | Setup | Pass standard (rises by level) |
|---|---|---|
| 20/20/20 full test | One full Academic Reading, strict thirds | L1: flag-and-move obeyed · L2+: +60–70% · L3+: 75%+ · L4: 85%+ |
| T/F/NG ladder | 15 statements, easy → brutal; justify each with the exact line | L1: 12+/15 · L2+: 13+/15 with zero unjustified |
| Paraphrase radar | From any passage: list 10 keyword→paraphrase pairs | 10 pairs in 10 min (L3: in 7 min) |
| Headings blind | Cover passage, write 1-sentence summary per paragraph from first lines | L1: 80% · L2+: 85%+ |
| Inference last | Passage done in 2 passes: factual Qs first, inference/writer-view second | +2 vs baseline (L3: hardest passages only) |

### Writing drills (20–45 min)
| Drill | Setup | Pass standard (rises by level) |
|---|---|---|
| Overview only | 5 different Task 1 visuals, write ONLY the overview (2 sentences each) | Each overview names the main trend with no numbers |
| Sentence surgery | Rewrite 5 of your own band-5/6 sentences (examiner-band-7-guide.md) | L1: 5 upgraded · L2+: 5 upgraded **from this week's own writing** |
| 40-min Task 2 | One full essay, 4-min plan enforced | L2: position consistent · L3: +35-min cap · L4: +35-min cap on an abstract topic |
| Proofread hunt | Re-read yesterday's essay hunting ONLY your personal top-5 error types | ≥ 3 self-caught errors (L3+: ≥ 4) |
| 60-min full writing *(L3+ only)* | Task 1 (20) + Task 2 (40), no pause | Weekly from Day 29; L4: both on hardest topic types |

### Speaking drills (20–30 min)
| Drill | Setup | Pass standard (rises by level) |
|---|---|---|
| 45-second answers | 8 Part 1 Qs, 20 s prep, record all | No answer under 3 sentences (L3+: must each contain one Tier-2/3 word) |
| 2-minute marathon | Part 2 cue card, speak the FULL time | L1: 2:00 no dead air > 3 s · L3+: abstract cue cards |
| P3 ladder | 5 abstract questions, Opinion→Reason→Example→Concession each | Concession in 4/5 (L4: 5/5 with a Tier-3 collocation each) |
| Playback audit | Re-listen at 1.2×, tag: repeats / stops / basic words | 3 fixes written into error log |

## Full Mock Protocol — escalating difficulty (Days 7, 14, 21, 28, 35)

| Mock | Day | Level | Conditions |
|---|---|---|---|
| Mock 1 | 7 | L1 | Standard Cambridge test, generous review time after |
| Mock 2 | 14 | L2 | Exam caps enforced; S3/S4 weighted review |
| Mock 3 | 21 | L2+ | Exam caps + no pauses between sections |
| Mock 4 | 28 | L3 | Hardest official materials (e.g., Cambridge 19 T3), 1.1× audio in one section |
| Mock 5 | 35 | L4 | Dress rehearsal: computer-delivered interface, over-speed listening, Task 2 in 35 min |

1. **Morning only** (mirrors real exam slot). L (30) → R (60) → W (60). Speaking: afternoon self-recorded Part 1–3 set.
2. **Score same day.** Use calibration table in examiner-band-7-guide.md.
3. **Classify every error** into the taxonomy: `paraphrase` / `spelling-plural` / `distractor` / `timing` / `technique` / `vocabulary` / `grammar`.
4. **Write the rollup:** 3 lines — what improved, what stalled, the ONE change for next week.
5. **Feed the loop:** top-3 error types become next week's AM lessons (see lesson-plans.md Week 4+).

Materials: Cambridge 15–19 tests — deliberately sequenced easier → harder across mocks; computer-delivered interface practice for Mocks 4–5.

## Exam Day Protocol (Day 39, Thu Oct 1)
- **48 h before:** light review of error-log rollups only. Sleep 8 h. No new material.
- **Morning of:** protein breakfast, arrive 45 min early, 10 min speaking warm-up out loud (Part 1 answers) to switch language on.
- **Listening:** use the preview pauses; transfer/enter answers immediately.
- **Reading:** 20/20/20, flag and move.
- **Writing:** 4/32/4 timing; hunt your personal top-5 errors in the final 4 min.
- **Speaking (same day or within 7 days):** warm up 15 min before slot; Part 3 = Opinion→Reason→Example→Concession.
- **After:** log the experience same evening; SAT takes over from Day 40 (sat/lesson-plans.md).
