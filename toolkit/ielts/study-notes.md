# IELTS Academic Study Notes — Targeting Band 7–7.5

Written against the four examiner criteria. Band 5/6 = "meaning is clear but mechanical"; band 7+ = "flexible, precise, controlled." Every section below ends with the habit that moves you up one band.

## How deep to go — by difficulty level
- **L1 (W1):** Sections 2–3 basics only — question shapes, prediction, overview sentence, 4-para skeleton. Ignore band-7 upgrades for now.
- **L2 (W2–3):** Add all "trap" and pacing notes; start the personal top-5 error list; first sentence-surgery attempts.
- **L3 (W4–5):** Everything marked band-7 becomes mandatory: varied linkers, referencing, concession structures, chunking/stress in speaking, 35-min Task 2 cap.
- **L4 (W6):** No new technique — re-read only your own error-log fixes and the One-Band Rule. Execution under exam pressure is the skill.

## 1. Listening (target 7.0 = 30–32/40)

**What examiners reward:** nothing subjective — it is pure answer accuracy. Band 7 = ~30 correct.

- **Prediction first:** before every audio, convert each question into the answer's shape: `a ____ of ____` (number+noun), name+spelling, date, place. Never press play cold.
- **Section tactics:**
  - S1/S2 (survival): watch for double dictations ("actually, make it Friday"), postcodes/numbers read digit by digit, prices with decimals.
  - S3 (academic discussion): track *who says what*; answers often from the second speaker; attitudes change mid-turn.
  - S4 (lecture): use the 30 s pause to read ALL questions; note-taking with symbols (→ causes, ↑ increase, e.g.).
- **Trap grammar:** plural -s (write "bookshops" not "bookshop"), hyphenation accepted both ways, numbers under 10 usually spelled in the transcript.
- **Spelling kills band scores:** any misspelling = wrong. Keep a personal "misspelled list" in the error log.
**Habit:** every wrong answer gets a taxonomy tag (paraphrase miss / spelling / plural / distractor) — after 2 weeks the pattern names your fix.

## 2. Academic Reading (target 7.0 = 30–32/40)

- **Pacing 20/20/20.** Flag and move. One passage is always hardest — do it second, not last, when focus is still high (test both orders in mocks).
- **Question-type playbook:**
  - T/F/NG: False must *contradict* the text; NG = plausible but unstated. Ask "do the words say this, or do I infer it?"
  - Matching Headings: match paragraph *topic sentence*, ignore details; headings paraphrase, never repeat words.
  - Summary completion: word bank tells you the word class; predict before scanning.
  - Multiple choice: eliminate 2 obviously-wrong, choose the paraphrase.
  - Writer's claims/views: locate the *attitude verb* (fails to, rightly, mistakenly).
- **Paraphrase radar:** IELTS never repeats keywords. Build the map: problem↔issue↔difficulty↔setback. Vocabulary tiers in vocabulary.md feed this.
- **Skim protocol:** 2 min/passage — first sentence of each paragraph + proper nouns + figures. Then scan for question keywords.
**Habit:** annotate passages with 4 codes: `=` paraphrase, `?` inference, `!` contrast, `#` example.

## 3. Academic Writing (target 6.5–7.0)

### Task 1 (150+ words, 20 min) — report, never opinion
- **Structure:** Intro (1–2 sentences: paraphrase the rubric) → Overview (the ONE paragraph that decides your TA band: the main trend(s), no numbers needed) → 2 body paragraphs grouping data logically.
- **Overview formulas:**
  - "Overall, X increased steadily over the period, while Y remained the largest category."
  - "Overall, the process consists of N main stages, beginning with… and ending with…"
- **Band-7 language bank:** whereas/while, by contrast, roughly/approximately/just under, peaked at, plateaued, a threefold increase, the reverse was true for.
- **Numbers hygiene:** mix percentages with fractions (a quarter of); never list every figure — *select and group*.
- **Processes:** passive voice dominates ("the mixture is then heated"); maps: was converted / was replaced by / had been demolished.

### Task 2 (250+ words, 40 min) — essay types: opinion / discussion / problem-solution / two-part
- **Band-7 skeleton:** Intro (paraphrase + clear position) → Body 1 (idea → explain → example) → Body 2 (same) → Conclusion (restate position, no new ideas).
- **TA 7:** position is *consistent* — every paragraph quietly supports it. Fully developed = 3–4 sentences per idea, not 2 ideas in 2 sentences.
- **CC 7:** one linker per ~2 sentences, varied (however, consequently, for instance); use referencing ("this approach", "such policies") — mechanical "Moreover… Moreover…" caps you at 6.
- **LR 7:** topic-precise vocabulary + collocations (impose a ban, a viable alternative, academic underachievement), 1–2 well-chosen idiomatic phrases max, no memorized phrases dropped in wrong contexts.
- **GRA 7:** mix simple + complex naturally: relative clauses, conditionals, concession ("Although X, Y"). Errors are allowed if they never block meaning — but *control* them: use structures you can land.
- **Timing discipline:** 4 min plan → 32 min write → 4 min proofread (checklist: plurals, articles a/the, subject-verb agreement, position consistency).
**Habit:** keep a "personal error top-5" from the error log; proofread hunts ONLY those five.

## 4. Speaking (target 6.5–7.0)

- **Part 1 (4–5 min):** answer + reason + detail, 3–4 sentences. Formula: "Directly, … because… , so…". Never one-word, never memorized-speech.
- **Part 2 (3–4 min):** 1 min notes as story beats (what/where/who/when/why memorable/feeling). Speak the full 2 minutes; if you finish early, add an anecdote ("What struck me was…").
- **Part 3 (4–5 min):** the band-7 engine. Pattern: **Opinion → Reason → Example → Concession** ("Admittedly, …, but …"). Abstract vocabulary from Tier 3.
- **FC 7:** speaks at length without effort; self-corrects hesitation with discourse markers (well, actually, to be honest).
- **LR 7:** less common vocabulary + collocations used naturally; paraphrase instead of stopping ("it's kind of a… what do you call it… a pavilion").
- **GRA 7:** flexible mix of simple/complex; typical band-7 structures: "If cities invested in…, commuting times would drop", "What I find fascinating is…".
- **P 7:** chunking (speak in sense-groups), sentence stress on opinion words, falling intonation to end ideas. Practice: read one Task-2 answer aloud daily, mark stress.
**Habit:** record one 2-minute answer daily; playback checklist: Did I repeat words? Did I stop mid-sentence? Did I give ONE example?

## The One-Band Rule
You improve the skill you *measure*. Every session ends in the error log with: counts (correct/incorrect), taxonomy tag, one-sentence root cause, and tomorrow's one-line fix. That loop — not extra hours — is what converts 6.0 work into 7.0 results.
