# SAT Practice Materials & Mock Exam Protocol

## Escalation Rules (difficulty must rise with the sprint)
- **L1 (W1):** easy–medium Bluebook sets, Desmos allowed on everything, generous pacing — target 60–70%.
- **L2 (W2–3):** medium sets at true module pace, Desmos timed not exploratory — target 75–80%. Same drill +5 points vs L1 or it repeats harder.
- **L3 (W4–5):** medium–hard sets, algebra-first on easy questions (Desmos only to verify), hard Module-2 simulations — target 80–85%.
- **L4 (W6):** hardest official questions, exam-strict timing, no-Desmos reflex drills — target 85–90% under pressure.
- Passed a drill? Retry it **one notch harder** (harder question bank, tighter clock, or tool restriction) — never the same difficulty twice.

### Mixed sets (Sat slot)
Alternate weekly: full R&W module (27 Q/32 min) ↔ full Math module (22 Q/35 min). L1–L2: standard modules. L3+: hardest available module variants. Always module-length — trains the adaptive-module mindset.

## Exam Day Protocol (Day 41, Sat Oct 3)
- **48 h before:** error-log rollups only. Verify device + Bluebook + charger + adapter. Sleep 8 h.
- **Morning:** protein breakfast, arrive 30 min early, 5 min Desmos finger-warmup (one system, one regression).
- **R&W Module 1:** protect accuracy — ceiling-setter. Bank time early.
- **Math Module 1:** same rule; no 3-minute questions.
- **Between modules:** 10-min break — water, movement, no post-mortems.
- **Slip checklist before each submit:** minus distributed? inequality flipped? units converted? answer actually asked (x vs y, mean vs total)? grid-in format legal?
- **After:** evening log of experience; portfolio sprint resumes Day 42.
