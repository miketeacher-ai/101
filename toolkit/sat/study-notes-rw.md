# SAT Reading & Writing Study Notes — Top Percentile Playbook

Digital SAT R&W: 54 questions, 64 min, two 32-min adaptive modules. Short passages (1–3 questions each). Average budget: ~71 s/question.

## How deep to go — by difficulty level
- **L1 (W1):** question-type playbook basics + predict-first habit. Ignore timing pressure.
- **L2 (W2–3):** all 8 grammar rules in rotation; module-pace drills begin; transition taxonomy memorized.
- **L3 (W4–5):** hard-module simulation, trap-choice analysis on every miss, synthesis at module pace.
- **L4 (W6):** execution only — slip checklist, hardest sets, no new technique.

## Module Strategy
- Module 1 accuracy sets Module 2 difficulty. Your score ceiling is decided in Module 1 — protect it: no question deserves 3 minutes there.
- Question order within a module ≈ easy → hard. Bank time early; expect the last 5 to be synthesis/logic-heavy.
- Flag-and-move is built in — use it twice per module maximum, revisit before submit.

## Question-Type Playbook

### Words in Context (~20%)
1. Cover the choices. Predict your own word.
2. Check *tone and direction* (positive/negative/neutral) before meaning.
3. The answer is a *precision* match, not a synonym list match. "Spare" ≠ "spare" (adjacent meaning beats identical look).
- Vocabulary source: sat/vocabulary.md + apps/vocab-trainer.html (SAT filter).

### Command of Evidence (~20%)
- For "Which finding best supports X?" — the answer must contain the *variable* X and the *direction* claimed. Eliminate findings about the wrong variable first.
- Quantitative evidence (tables): recompute the claim yourself; the trap is a true-looking statement about the wrong rows.

### Inference (~15%)
- "Strongly suggests" = must be true from the text, not from life. The correct answer is usually a *moderate* restatement; extreme words (always, never, only, most) mark traps.

### Main Purpose / Text Structure (~10%)
- One-sentence test: "The author is trying to *change my mind about / explain / evaluate* ___."
- Structure answers: generalization→example, problem→solution, claim→counterexample. Match the *function*, not the topic.

### Cross-Text / Paired (~5%)
- Map: Text A claims P; Text B claims Q. Q1 asks how B responds → look for agreement/disagreement on the *same claim*, not the same topic.

### Transitions (~10%)
Taxonomy: **contrast** (however, nevertheless, still, even so) · **cause-effect** (therefore, consequently, thus, hence) · **addition** (moreover, furthermore, similarly, likewise) · **example** (for instance, specifically) · **sequence** (subsequently, meanwhile, ultimately).
Method: read the two sentences, decide the logical relationship FIRST, then pick the word. If two choices fit, the *stronger* relationship word wins.

### Boundaries / Form / Structure (Grammar, ~20%)
Eight rules, in order of exam frequency:
1. **Sentence boundaries:** comma splice = wrong; period/semicolon/`, and` fix it.
2. **Verb SVA:** strip prepositional phrases ("the collection *of letters was*…"); watch collective nouns, "each/either".
3. **Pronouns:** must match true antecedent (number + case); "their" for singular noun = trap.
4. **Verb tense:** anchor to the timeline; past-perfect only for earlier-of-two-pasts.
5. **Modifiers:** -ing/-ed openers must touch the doer.
6. **Parallelism:** lists and comparisons keep identical forms.
7. **Apostrophes:** possessive vs plural; "its = possessive / it's = it is".
8. **Punctuation of non-essentials:** paired dashes or paired commas, never mixed.

### Rhetorical Synthesis (~10%, always hardest)
Bulleted notes + "Which choice most effectively meets the goal?" — the answer must satisfy **ALL** bullets; one unsatisfied bullet = eliminated. Read the *goal sentence* twice; it overrides style.

### Transitions of Logic in Data Questions
When a question cites a table/model: verify *units* and *direction* before reading choices. Most wrong answers misstate the trend, not the numbers.
