# Daily Error Log — The Metacognition Engine

**Mandatory every study day, both exams.** The log is the highest-leverage 15 minutes of the schedule: it converts practice into targeted improvement. Digital version: `apps/error-log.html` (auto-counts, exports CSV). This file is the printable/manual standard.

## The Rule
Every session ends with three entries: **counts, classification, reflection.** No entry = the session doesn't count as done. Sets must **climb the ladder**: if the logged level is flat for a full week, the next week's sets move up one level (README ladder) — difficulty is a requirement, not an option.

```

**Task/Set:** (e.g., Cambridge 17 T3 Reading / Bluebook Math M1)
**Set level:** L1 / L2 / L3 / L4 — must match the week's rung on the ladder (README); never flat across weeks

**Counts**
| Attempted | Correct | Incorrect | Accuracy |
|-----------|---------|-----------|----------|
|     |     |     |    % |

**Classification (per incorrect answer)**
| # | Question ref | Error type | Root cause (1 line) | Fix scheduled (day) |

| 1 | R Q23 | paraphrase miss | mapped keywords, not meaning | redo pair-drill Day __ |
| 2 | M Q14 | algebra slip | minus not distributed | slip checklist before submit |

**Reflection (mandatory, 2–4 sentences)**
- What challenged me most today, and why:
- The pattern I see across today's misses:
- ONE change for tomorrow:
```

## Error Taxonomy (use these tags consistently)

| Tag | Meaning | Typical countermeasure |
|---|---|---|
| `concept` | Didn't know the rule/method | AM lesson redo (lesson-plans.md) |
| `algebra-slip` | Knew it, executed wrong | Slip checklist before submit |
| `careless` | Misread/typo/answered wrong thing | Box-the-question ritual |
| `timing` | Rushed or ran out | Segment budget drill (practice-and-mocks.md) |
| `paraphrase` | Missed the rewording (IELTS R/L, SAT WIC) | Paraphrase radar pair-drill |
| `trap-choice` | Chose the seductive wrong option (SAT MC) | Predict-first protocol |
| `vocabulary` | Word unknown/confused | vocab-trainer + log the pair |
| `format` | Grid-in/transfer/spelling error | Format gauntlet drill |
| `Desmos` | Calculator misuse | Calculator guide section redo |

## Quality Bar for Reflections
- Weak: "Reading was hard today."
- Strong: "Missed 3 T/F/NG because I matched words instead of meaning — all 3 had a paraphrase (problem→setback). Tomorrow: justify every T/F/NG with the exact line before answering."
- The test: could a tutor diagnose your day from the entry alone?

## Streaks & Honesty
- Log misses from mocks the SAME day (mock protocol step 3).
- Accuracy is per set; track the *trend* per error type, not per day.
- If accuracy is rising but error count is flat, you're drilling easy sets — raise difficulty (practice-and-mocks.md pass standards).
