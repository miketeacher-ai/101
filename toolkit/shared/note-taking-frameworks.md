# Note-Taking Frameworks — For Study, Class, and Exam Day

Notes exist to be *attacked later*, not admired. Pick the framework per task; every framework ends in the error log.

## 1. Cornell Notes (default for lessons & study notes)
Page split: **Cue column (left, 25%) | Notes (right, 70%) | Summary (bottom, 5 lines).**
- During: notes right, formulas/examples verbatim.
- Within 24 h: write questions in the cue column that the notes answer ("Why flip the inequality sign?").
- Weekly: cover the notes, answer your own cues aloud. Failures → error log.
- Best for: SAT math domains, IELTS writing criteria, grammar rules.

## 2. QEC Error Notes (for every practice miss)
**Q**uestion (what was asked, in 5 words) → **E**rror (what I did) → **C**orrection (the rule/insight, one line).
- Example: `Q: system no-solution? | E: compared slopes only | C: parallel needs equal slope AND different intercept; coincident = both equal.`
- The C line must be *usable by a stranger*. If not, you don't understand it yet.

## 3. Charting (for comparison-heavy content)
Grid with column headers (e.g., Tense | Use | Signal words | Example). Fill while reviewing; blank cells = quiz list. Best for: grammar rules, question-type playbooks, vocabulary connotation ladders.

## 4. Mapping / Mind Map (for essay & speaking planning)
Center = topic; 4 branches max; each branch = one paragraph/idea; leaves = example + linkers you'll use. The 4-minute Task 2 plan IS this map, drawn small.

## 5. Exam-Day Annotation Codes (working memory offload)
**IELTS Reading:** `=` paraphrase found · `?` inference needed · `!` contrast/however · `#` example · `□` unanswered.
**IELTS Listening:** abbreviations: `w/` with, `→` leads to, `↑↓` increase/decrease, `∴` therefore, `≈` about, `esp.` especially; numbers: circle units (%, £, date).
**SAT R&W:** underline the *relationship word* (however/therefore) in transition Qs; bracket the claim sentence; cross out violated synthesis bullets immediately.
**SAT Math:** box what's ASKED (x? y? total? mean?); circle unit conversions before computing; write the check line (`sub x back`).

## 6. The Scratch-Work Discipline (SAT Math)
- One consistent grid: question number top-left of scratch area; work top-down, never sideways chaos.
- Write the operation line before the arithmetic line ( `(1.2)(350) = ` then compute).
- Final answer circled BEFORE looking at choices — stops trap-choice seduction.

## 7. Weekly Synthesis Ritual (Sunday, 20 min)
1. Read the week's QEC lines only (not the questions).
2. Group into top-3 error themes; write one countermeasure per theme.
3. Schedule each countermeasure into next week's AM slots (lesson-plans.md).
4. One-line journal: "The thing that actually moved my score this week was ___."

## Digital vs Paper
- Paper for: math scratch work, Cornell during lessons, exam-day annotation (matches real exam conditions).
- Digital for: error log (apps/error-log.html — searchable, exports CSV), vocabulary spaced repetition (apps/vocab-trainer.html).
